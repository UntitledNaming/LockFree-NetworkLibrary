# Test Report

이 문서는 P1 네트워크 라이브러리를 검증한 테스트의 목적·조건·결과를 정리합니다. 확정된 수치만 사용하고, 아직 판독·정리되지 않은 정량 값은 TODO로 표시합니다.

---

## 1. 테스트 목적

- **안정성 검증**: 여러 서버를 장시간 구동해 무중단·연결 안정성을 확인한다.
- **멀티스레드 채팅 서버 검증**: 컨텐츠 처리를 단일 스레드로 직렬화한 버전과 락 기반 멀티스레드 버전을 비교한다.
- **더미 클라이언트 기반 부하 테스트**: 다수 접속·송수신 부하에서 서버 안정성을 확인하고, 측정 도구 자체의 병목까지 분석한다.

## 3. 장시간 테스트

- **무중단 테스트**: 채팅 서버 7일 무중단, 게임 서버 7일 연결. 장시간 동안 세션 누수·크래시 없이 유지되는지 확인.
- **인증 테스트**: 채팅-로그인 5일 인증. 로그인 서버가 토큰을 발급하고 인증 채팅 서버가 이를 검증하는 경로가 장시간 유지되는지 확인.
- **관측 지표**: 각 서버가 모니터링 클라이언트로 보낸 TPS·CPU·메모리·TCP 재전송 등을 모니터링 서버에서 관측.
- **다운 클라이언트 / 연결 실패 로그**: 더미 측 로그(연결 실패·다운 클라이언트 기록)를 무중단 판정 근거로 사용. (해당 로그는 더미 프로그램 폴더에 기록됨)


---

## 4. 결론

- 하나의 네트워크 라이브러리를 성격이 다른 여러 서버(채팅 싱글/멀티/인증·로그인·모니터링·게임)에서 검증해, 안정성과 확장성을 함께 확인했다.
- "중첩 IO가 항상 빠르다"가 아니라 메시지 크기에 따라 최적 송신 방식이 다르다는 점을 측정으로 확인했다.
- 측정 과정에서 서버가 아니라 측정 도구(더미 클라이언트)가 병목이 되는 상황을 발견하고 보정해, 측정 환경 자체의 공정성까지 데이터로 검증했다.

> 문제 발견과 해결 과정의 상세는 `docs/Troubleshooting.md`를 참고하세요.
