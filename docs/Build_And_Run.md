# Build & Run

이 문서는 README보다 자세한 빌드·실행 안내입니다. 실제 IP·포트·계정·비밀번호 같은 민감 정보는 넣지 않으며, Config 키 이름과 예시만 적습니다. 환경에 따라 값은 직접 설정해야 합니다.

---

## 1. 개발 환경

- OS: Windows
- IDE: Visual Studio 2022
- 언어 표준: C++17
- 네트워크: WinSock2 / IOCP
- 데이터베이스: MySQL (계정·로그 DB)
- 캐시/토큰 저장소: Redis (로그인/인증 경로에서 사용)
- 성능 지표: PDH (Windows 성능 카운터) — 모니터링에 사용

> Redis는 로그인 서버와 인증 버전 채팅 서버에서만 사용합니다. 채팅 단독·게임·모니터링 서버 테스트에는 필요하지 않습니다.

---

## 2. 빌드 방법

- 각 서버는 `servers/` 아래에 개별 솔루션(`.sln`)으로 구성되어 있습니다. 테스트하려는 서버의 솔루션을 Visual Studio 2022로 엽니다.
- 빌드 구성은 x64 / Release를 기준으로 합니다.
- include/lib 경로: 각 프로젝트가 참조하는 공용 헤더는 `common_files`, `network_library`, `game_library`에 있습니다. 서드파티(MySQL 클라이언트)는 각 서버 프로젝트의 ThirdParty 경로를 참조합니다.
- 추가 종속성: 로그인/인증 관련 서버는 MySQL 클라이언트 라이브러리와 `cpp_redis`가 필요합니다. 네트워크 서버는 `Ws2_32.lib`, 모니터링 관련은 `Pdh.lib`을 링크합니다.
- 빌드 대상: 테스트하려는 서버(예: 모니터링 서버, 채팅 서버, 로그인 서버, 게임 서버)와 필요한 더미 프로그램.

> 정확한 프로젝트별 참조 경로·라이브러리 목록은 각 `.vcxproj` 설정을 따릅니다. 환경에 맞춰 include/lib 경로를 조정해야 할 수 있습니다. 

---

## 3. 실행 순서

서버는 의존 관계가 있어 순서가 중요합니다. 대략적인 순서는 다음과 같습니다.

1. **Redis 실행** (로그인/인증 테스트 시): `redis/` 폴더의 Redis 서버를 실행합니다.
2. **DB 준비**: MySQL을 설치하고 `DB/` 폴더의 스키마(계정 DB, 로그 DB 등)를 적용합니다.
3. **모니터링 서버 실행**: 다른 서버들이 지표를 보낼 대상이므로 먼저 구동합니다.
4. **로그인 서버 실행** (로그인/인증 테스트 시): DB·Redis 접속 정보와 모니터링 서버 정보를 Config에 설정한 뒤 구동합니다.
5. **채팅 / 게임 서버 실행**: 테스트 대상 서버를 구동합니다. 각 서버 Config에 모니터링 서버 정보를 설정합니다.
6. **더미 클라이언트 실행**: 대상 서버에 맞는 더미 프로그램의 Config(서버 IP·Port 등)를 설정하고 실행해 부하를 만듭니다.

> 각 서버의 Config 파일에서 서버 IP·Port, DB 접속 정보, Redis 접속 정보, 모니터링 서버 정보, 라우팅 정보를 설정합니다. 키 이름은 각 서버의 Config 파일을 참고하세요.

---

## 4. 테스트 실행

테스트 시나리오별로 필요한 서버 구성은 다음과 같습니다.

- **게임(에코) 서버**: 모니터링 서버 → 게임 서버 → 게임 더미. 게임 라이브러리의 그룹·프레임·그룹 이동을 검증.
- **채팅 서버(단독)**: 모니터링 서버 → 채팅 서버 → 채팅 더미. 단일/멀티 버전을 각각 테스트해 비교.
- **로그인 인증 테스트**: Redis → 모니터링 서버 → 로그인 서버 → 인증 버전 채팅 서버 → 로그인 연동 더미. 로그인이 토큰을 발급하고 인증 채팅 서버가 이를 검증하는 경로를 확인.
- **모니터링**: 모니터링 서버를 먼저 띄우고 각 서버가 지표를 보내는지 확인.
- **더미 클라이언트**: 각 더미의 Config에 대상 서버 IP·Port를 설정해 실행. 부하 생성 및 연결 실패·다운 클라이언트 로그 확인.

> 더미 클라이언트는 이 레포에 실행 파일·설정·로그 형태로 포함되어 있습니다. 소스는 포함되어 있지 않습니다.

---

## 5. 주의사항

- 실제 서버 IP·Port, DB 계정/비밀번호, Redis 접속 정보는 저장소에 포함하지 않습니다. 각 환경의 Config 파일에서 직접 설정하세요.
- 개인 PC의 절대경로(설치 위치 등)는 저장소에 넣지 않습니다.
- 환경에 따라 IP/Port, DB·Redis 접속 정보, include/lib 경로를 수정해야 합니다.
